# 表情识别交互式桌宠

一个基于表情识别的交互式桌面宠物应用，能够通过摄像头实时检测用户面部表情并做出相应互动。

## ✨ 功能特性

### 🎭 实时表情识别
- 使用 MediaPipe 进行面部特征点检测
- 识别多种表情：开心、难过、愤怒、惊讶、恐惧、平静
- 智能表情校准系统
- 实时可视化表情分析结果

### 🐾 桌宠互动
- 根据用户表情变化做出不同反应
- 自动或手动控制桌宠移动
- 表情触发时显示对应的对话气泡
- 支持拖动、隐藏/显示等交互

### 🛠️ 系统功能
- 系统托盘图标控制
- 窗口置顶/取消置顶
- 自动移动开关
- 透明窗口支持
- 自适应窗口大小调整

## 📁 项目结构

```
project/
├── pettest.py              # 主程序文件
├── expressionlatest.py     # 表情识别引擎

├── resource/               # 桌宠动画资源
│   ├── 0/                 # 向左方向动画

│   │   ├── 1.gif         # 开心状态
│   │   └── ...

└── README.md
```

## 🚀 快速开始

### 环境要求
- Python 3.7+
- Windows 系统（因使用了 Windows API）
- 摄像头设备

### 安装依赖
```bash
pip install pygame pystray pillow opencv-python mediapipe numpy
```

### 下载模型文件
1. 从 [MediaPipe 官网](https://developers.google.com/mediapipe/solutions/vision/face_landmarker) 下载 `face_landmarker.task` 模型文件
2. 将文件放置在项目根目录下

### 运行程序
```bash
python pettest.py
```

## 🎮 使用说明

### 系统托盘控制
程序启动后会在系统托盘显示图标，右键点击可：
- **显示/隐藏**：切换桌宠显示状态
- **自动移动**：开启/关闭桌宠自动移动
- **窗口置顶**：设置窗口是否始终置顶
- **退出**：关闭程序

### 表情识别
- 程序启动后会自动打开摄像头窗口
- 保持自然表情 20 帧完成校准
- 根据面部表情变化，桌宠会做出相应反应：
  - 😊 开心 → 桌宠微笑，显示开心对话
  - 😢 难过 → 桌宠安慰，显示鼓励对话
  - 😠 愤怒 → 桌宠生气，显示安抚对话
  - 😲 惊讶 → 桌宠惊讶，显示好奇对话

### 窗口操作
- **拖动**：点击桌宠身体部位可拖动窗口
- **自动贴边**：松开后自动贴到任务栏边缘
- **隐藏**：可通过托盘菜单隐藏窗口

## ⚙️ 配置说明

### 资源文件
动画资源位于 `resource/` 目录下，按方向和状态分类：
- `0/`：向左方向的动画
- `1/`：向右方向的动画
- 每个目录包含多种状态动画

### 表情识别参数
在 `expressionlatest.py` 中可调整：
- 表情识别灵敏度
- 校准所需帧数
- 表情判断阈值
- 渲染字体和颜色

### 桌宠参数
在 `pettest.py` 中可调整：
- 桌宠大小和位置
- 移动速度和间隔
- 气泡显示时间
- GIF 动画缩放比例

## 🔧 常见问题

### 1. 摄像头无法打开
- 检查摄像头是否被其他程序占用
- 确保摄像头权限已开启
- 尝试重启程序

### 2. 表情识别不准确
- 确保环境光线充足
- 面部正对摄像头
- 校准过程中保持平静表情
- 按 'R' 键可重新校准

### 3. 模型文件缺失
```
错误：未找到模型文件 face_landmarker.task
```
请从 MediaPipe 官网下载模型文件并放置在项目根目录。

### 4. 中文字体显示异常
程序会自动尝试加载系统字体，如仍无法显示，可在 `expressionlatest.py` 中修改字体路径。

## 📝 注意事项

- 程序使用 Windows API 实现窗口特效，仅支持 Windows 系统
- 表情识别功能需要摄像头支持
- 资源文件路径为相对路径，请勿随意移动文件位置
- 退出时请使用托盘菜单，确保资源正确释放
